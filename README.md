# ViaVoice

A small Fabric addon for **Simple Voice Chat**.

I made this because I could join servers on a different Minecraft version, but voice chat wouldn't connect. ViaVoice tries another supported voice chat protocol when the server rejects yours.

### Setup
Install **Simple Voice Chat** and **Fabric API**.
No configuration or server-side addon needed.

### Compatibility
Supports voice chat protocols **18, 19 and 20**.

Tested with:
- **1.20.1** — Voice Chat 2.5.36 / 2.6.24
- **1.21.11** — Voice Chat 2.6.24
- **26.1.2** — Voice Chat 2.6.24
- **26.2** — Voice Chat 2.6.22

Other combinations might work, but I haven't tested everything.

ViaVoice only handles voice chat compatibility. You still need something like **ViaFabricPlus** to join different Minecraft versions. It won't fix blocked voice chat ports or proxy forwarding issues.

If you find a problem, please include your client and server versions and a client log.

Thanks to [henkelmax](https://modrinth.com/plugin/simple-voice-chat) for Simple Voice Chat. This is an independent addon.
